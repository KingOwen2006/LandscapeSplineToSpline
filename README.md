# LandscapeSplineToSpline
This is a plugin for Unreal Engine 5.7.4 that turns any landscape spline into a spline component

# How to install
1. if you have the Unreal Editor open please close it. 
2. Open your game in file explorer <img width="623" height="348" alt="image" src="https://github.com/user-attachments/assets/02ac21d4-02a3-40ab-8b81-f3244a0ca814" /> make sure you have the plugins folder if not you can create it.
3. Unzip the file
4. Move it into the plugins folder. That's it your all set.

# How to use
1. Open your project and go to edit -> plugins and look for LandscapeSplineToSpline and enable it. If not enabled your editor may ask for a restart.
2. Once your engine has restarted <img width="827" height="280" alt="image" src="https://github.com/user-attachments/assets/8f5696b3-6707-4f08-b4f7-cb2e7a4969ea" /> Press the cube with the plus and look for LandscapeSplineToSpline. Click it and it has added an actor to your world.
3. Aftwards click on it <img width="325" height="912" alt="image" src="https://github.com/user-attachments/assets/5047d432-c2f9-4ed5-a35f-b383b8f931d8" /> and play with the values until you get your desired settings.

# Support
It supports many spline actor in 1 level. It supports overlaping splines.
